# User Story — 인덱스

유저스토리 작성 가이드와 PRD 내 추적성 규칙을 모아둔 폴더입니다.
PRD 의 모든 props/variants/states/접근성은 **유저스토리에서 도출**되어야 한다는 본 시스템의 핵심 추적성 룰이 여기서 시작합니다.

## 파일 매핑

| 수정하고 싶은 내용 | 어떤 파일을 보면 되는가 |
|---------------------|-------------------------|
| 유저스토리 작성 형식 (As a / I want / so that) 과 추적성 정책 | [user-story01-writing-guide.md](./user-story01-writing-guide.md) |

## 갱신 규칙

- 위 항목 중 하나의 내용을 **수정**할 때는 해당 파일을 직접 편집합니다.
- 다음과 같은 **새 내용**은 다음 번호의 새 md 파일로 추가합니다:
  - 페르소나/역할 정의 (`user-story02-personas.md`)
  - 유저스토리 분류 체계 (필수/선택, 우선순위 등)
  - 컴포넌트 군별 표준 유저스토리 모음
